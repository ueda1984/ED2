# From the published QS³ (QS-Cube/ED) to unpublished ED2: code-verified scope matrix

**Primary manuscript baseline: [QS-Cube/ED](https://github.com/QS-Cube/ED),
the source of the published QS³ paper,
*Computer Physics Communications* **277**, 108369 (2022),
DOI [10.1016/j.cpc.2022.108369](https://doi.org/10.1016/j.cpc.2022.108369).**

**Target of this first ED2 paper:** the generalized
[QS-Cube/ED2](https://github.com/QS-Cube/ED2) software,
including the reviewed numerical-maintenance and reproducibility
changes on the development fork. **ED2 has a public GitHub
repository but no established prior journal program article.**
Publication status and public-source status are *not* synonyms.
An eventual integrated, released program revision and the authorized
article author list require maintainer decisions.

## 1. Direct inspection of the original program

The *original* `QS-Cube/ED` explicitly describes itself as
`QS³ for ED`, intended for spin-1/2 XXZ-type Hamiltonians
near full polarization. Its main program reads the fixed
number `NOD` of down spins, with a basis dimension
\(\binom{L}{N_\downarrow}\), and can also exploit
site-permutation/translation momentum blocks.
Its input format contains `NOxxz` and `FILExxz`,
with two numerical exchange parameters per bond:
an XY exchange and a longitudinal ZZ exchange.
The separate original `source_only_u1` implementation
handles a fixed-\(N_\downarrow\) sector without translations.

The old source includes `source_DSFLan` and a
`cal_dsf` pathway with dynamical structure factors
generated by Lanczos recursion. Its sample driver
builds `QS3`, `QS3_only_u1` and `DSFLan`
executables and runs dynamic examples. These
features were implemented in the original program:
**do not treat static Cartesian correlations in ED2
as a replacement for spectral/dynamic DSF capability.**

The original production code already uses
Lanczos/thick-restart eigensolvers, dense
LAPACK diagonalization, OpenMP and symmetry-adapted
state enumeration. Do **not** present those standard
methods as new ED2 inventions.

## 2. Direct inspection of the generalized ED2 code

The ED2 `source/input_param.f90` contains
site-specific `local_spin` and `local_NODmax`,
global excitation limits `NODmin` and `NODmax`,
bond records `Jint(1:9)` and site-field
`hvec(1:3)`, and user-specified site
permutations/characters `L1..L6` and `M1..M6`.
These inputs are *already in* the 2026
public QS-Cube/ED2 main source and are
not creations of the current fork.

The ED2 `source/ham2vec.f90` handles nine
bilinear coupling components per oriented
bond: \(J_x,J_y,J_z,D_x,D_y,D_z,
\Gamma_x,\Gamma_y,\Gamma_z\).
Unlike the original spin-1/2 `NOD`-fixed
calculation, an ED2 full-space run can include
all local occupations at different spin values,
so \(S^z_{\rm tot}\)-breaking interactions
need not be projected into an artificial
constant-magnetization block.

Current ED2 `source/main.f90` computes
low-energy levels, local Cartesian spin
expectations and a requested list of
Cartesian two-body correlations. A
`cal_dsf` option or old `DSFLan`
executable is **not** present in the
currently inspected ED2 main source.
A future generalized DSF implementation
is therefore a potential extension,
**not a feature of the submitted ED2
program as presently evidenced**.

| Scientific/software capability | Published original QS³ (QS-Cube/ED) | Unpublished generalized ED2 (current target) | Honest paper positioning |
| --- | --- | --- | --- |
| Local spin | Uniform 1/2 | User-defined site-dependent \(S_i\) | Major model-space extension |
| Two-body exchange | XXZ, XY+ZZ entries | Independent \(J_x,J_y,J_z\), directed \(D_{x,y,z}\), symmetric \(\Gamma_{x,y,z}\) | General operator/model extension |
| Site-specific fields | Baseline code has a limited field pathway | Three Cartesian site-dependent field components | Explicit Hamiltonian input extension |
| Basis | Fixed `NOD` and optional momentum | Local occupation caps, `NODmin/NODmax` window, identity or user-specified symmetry representation | Use full space when U(1) is broken; distinguish projected windows from symmetry sectors |
| Hamiltonian dimension | \(\binom{L}{N_\downarrow}\), before spatial reduction | Complete \(\prod_i(2S_i+1)\), or a selected/projected representation | Cannot compare max site counts at different dimensions |
| Local and pair observables | \(S^z\), \(S^zS^z\), \(S^+S^-\), static outputs | \(\langle S_i^{x,y,z}\rangle\), nine Cartesian \(\langle S_i^\alpha S_j^\beta\rangle\) | Enables full vector chirality and off-diagonal response checks |
| Dynamics | Includes dedicated `DSFLan` / dynamical structure factor pathway | No equivalent native `cal_dsf` or `DSFLan` pathway confirmed in current executable | **Not** a blanket superset; note as absent/unverified |
| Eigenvalue algorithms | Lanczos, thick-restart Lanczos, dense LAPACK | Same mathematical solver families | No new solver theory claimed |
| Parallelism | OpenMP already used | OpenMP retained | Not a new parallel paradigm |
| Operator cache | No matching current `wk_dim`/`MNTE` interface in old inspected sources | User-configurable cache rows/capacity | ED2 implementation feature; not necessarily universal performance benefit |
| Reliability engineering | Earlier numerical and I/O behavior | Explicit LAPACK interfaces, fixed sparse-field indexing, numerical/residual diagnostics in fork development | Secondary implementation correctness, not sole journal novelty |

**Input-output nonidentity matters.** The old program's
legacy dynamic inputs and `source_only_u1` options
must not be presented as directly interchangeable
with ED2's `NODmin/NODmax`, local-spin and nine-term
bond records. A physical Hamiltonian must be
*translated*, and compared at the same Hilbert-space
target, before any numerical comparison is meaningful.

## 3. Explicit overlap: identical physical XXZ sector

We added a source-pinned
[old-versus-new cross-check program](https://github.com/ueda1984/ED2/blob/codex/ed2-cpc-stationary-dm-scaling/tests/cpc_qs3_ed_shared_xxz_crosscheck.py)
which checks **the same Hamiltonian**
for \(L=4\), \(S_i=1/2\),
\(N_\downarrow=2\), open boundaries,
\(J_{xy}=0.8\), \(J_z=1.1\).

The old program uses `QS3_only_u1`
and a 6-dimensional fixed-NOD dense sector.
ED2 sets `NODmin=NODmax=2`,
`J_x=J_y=0.8`, `J_z=1.1`, with
all DM, Gamma and fields zero,
and uses a 6-dimensional projected sector
which is **exact** here because
\(S^z_{\rm tot}\) is conserved.
Both use ALG=3 (dense LAPACK) to
avoid Krylov iteration and starting
vector differences. A third, separately
written NumPy product-state Hamiltonian
checks all six eigenvalues.

The [pinned-source CI workflow](https://github.com/ueda1984/ED2/actions/workflows/cpc-legacy-qs3-ed2-crosscheck.yml)
checks out the exact old Git SHA, builds
the historical `source_only_u1` and
a freshly extracted ED2 source archive,
and retains all original input decks,
stdout and eigenvalues. The historical
program's Fortran source is not edited;
a legacy compatibility *compiler flag*
is documented separately from physical
source changes.

**Verified result:** [successful CI #43712076117](https://github.com/ueda1984/ED2/actions/runs/43712076117),
using the original Git SHA `a3b09934bba5f966bfb564718528de8778c2b46c`
and tested ED2 SHA `88c72032c26e52e507bc1217ec030479ada486fc`,
returned **all six levels correctly**.

| Comparison of six eigenvalues | Maximum absolute difference |
| --- | ---: |
| Original QS³/ED versus separately assembled exact sector | 3.3306690738754696e-16 |
| Generalized ED2 versus separately assembled exact sector | 2.6645352591003757e-15 |
| Original QS³/ED versus ED2 | 2.886579864025407e-15 |

The full [six-row source-identified spectrum CSV](cpc-qs3-ed-ed2-shared-xxz-spectrum-ci.csv)
and GitHub Actions [archived input decks / complete solver outputs](https://github.com/ueda1984/ED2/actions/runs/43712076117)
preserve the measured results. This is an actual
**three-way physical-spectrum agreement**, not a claim
that all old QS³ inputs are automatically compatible
with ED2, that old dynamic response has been
ported, or that ED2 is faster on matched workloads.
Observed elapsed times for these tiny dense solves
are explicitly **not** used for performance comparisons.

### 3.1 Extension into the original near-saturation sector and larger conserved sector

We also compiled and directly executed both programs
in an **expanded three-case same-physics suite**
([successful CI #43712595377](https://github.com/ueda1984/ED2/actions/runs/43712595377)).
It tests a \(L=6\), \(N_\downarrow=1\)
near-saturation case and a
\(L=6\), \(N_\downarrow=3\)
half-filled sector alongside the
original \(L=4,N_\downarrow=2\)
fixture, using the same OBC
\(J_{xy}=0.8,J_z=1.1\) Hamiltonian.
The test does not use the
old dynamics program or imply
a matched-runtime speedup.

| Physical sector | Hilbert dimension | Maximum original QS³–ED2 difference |
| --- | ---: | ---: |
| \(L=4,\ N_\downarrow=2\) | 6 | 2.89e-15 |
| \(L=6,\ N_\downarrow=1\) | 6 | 7.77e-16 |
| \(L=6,\ N_\downarrow=3\) | 20 | 2.89e-15 |

The **32/32 eigenvalues** agree
across both executable codes,
and each run is also checked against
a third independent full
product-sector Hamiltonian.
The largest individual
disagreement with that
independent reference is
\(3.44\times10^{-15}\)
for ED2 and \(1.55\times10^{-15}\)
for original QS³ across the
three cases. This comparison
includes both the original
software's intended dilute
down-spin regime and a larger
conserved sector.

All 32 actual measured eigenvalues,
reference eigenvalues and differences
are permanently preserved in the
[frozen extended 32-level CSV](cpc-qs3-ed-ed2-32level-extended-ci.csv),
including the original/source
SHAs and CI job identity.
A CI artifact temporarily
retains the full original and ED2
input, stdout and spectrum output.
These measurements are **not**
supplemented with fabricated
memory, speed or source-compatibility
results.

## 4. What should be the contribution in the first ED2 paper?

The central program-level novelty relative to
the **published** old QS³ is **the generalized
mixed-spin/non-U(1) operator and Hilbert-space
construction**, not the fact that a fork
recently acquired more tests.

An effective article can present:

1. The **specific extensions** to local
   occupations, local spin matrices,
   nine-component bond operators,
   site fields and symmetry/basis inputs,
   with a compact example of the new
   Hamiltonian action.
2. The **controlled continuity** with
   old QS³ in a common U(1) XXZ sector.
3. A **non-U(1) scientific application**
   that is not representable in the old
   XXZ input model: the alternating-spin
   XYZ/Gamma/staggered-DM chirality response,
   independently verified through \(L=12\).
4. **Quantitative resource properties**
   of ED2's current representation/cache,
   including an exact model-dependent
   cache capacity formula and matched
   physical output checks; do not claim
   a general speedup from shared CI timings.
5. **Engineering confidence**, including
   error handling, numerical residuals,
   reproducible source packaging and
   public worked examples.

The original QS³ dynamic-structure-factor
and low-density-large-\(L\) use cases
remain valuable but **are not the
same benchmark target** as unrestricted,
mixed-spin ED2. Do not compare memory,
wall-time or maximum lattice size between
these fundamentally different workloads.
